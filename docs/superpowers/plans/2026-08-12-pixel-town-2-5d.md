# 东方像素 2.5D 小镇 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 SVG 平面画卷升级为可拖动缩放、可访问、可降级的东方像素 2.5D 小镇，并同步升级烦恼详情主视觉、后台摆放和旧坐标迁移。

**Architecture:** 服务端继续通过现有公开仓储读取烦恼、生命、成长阶段和摆放数据，再由纯函数 `WorldAdapter` 生成可序列化的 `TownWorldModel`。React 管理页面状态、DOM 热点、路由、正文和错误降级；动态加载的 `@pixi/react` / PixiJS 只管理场景图、动画、相机和编辑命中。公共场景、后台编辑器和迁移脚本共享同一布局配置、坐标投影和素材清单。

**Tech Stack:** Node.js 22、Next.js 16 App Router、React 19、TypeScript、PixiJS 8.19.0、@pixi/react 8.0.5、Prisma 7 / SQLite、Zod、Vitest、Testing Library、Playwright、CSS Modules。

**Specification:** `docs/superpowers/specs/2026-08-12-pixel-town-2-5d-design.md`

---

## 实施边界

本计划是一条连续交付链，而不是三个独立产品：

1. **场景基础**：版本化布局、世界模型、资源清单、相机和灰盒 PixiJS 场景。
2. **公共体验**：渐进加载、DOM 热点、东方像素素材、环境动画和详情页主视觉。
3. **策展闭环**：安全位置 API、所见即所得编辑器、旧坐标预览与迁移。
4. **交付加固**：无障碍、错误降级、性能基准、端到端与构建验证。

不要增加角色自由行走、碰撞、任务、昼夜天气、实时多人、真 3D、全站像素化或素材上传。
